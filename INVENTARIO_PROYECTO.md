# ESTADOS

- Planificado: definido pero no entregado.
- Entregado: existe como artefacto oficial del proyecto.
- Congelado: entregado y establecido como estable.
- Completado: nivel o conjunto de trabajo formalmente cerrado.

---

# REGLA DE ACTUALIZACION

Este inventario debera actualizarse durante `condorcerrar`.

La entrega de un documento no equivale al cierre del nivel.

Al cerrar un nivel deberan reflejarse:

- artefactos efectivamente entregados;
- versiones vigentes;
- estado de congelamiento;
- estado del nivel;
- linea base cuando corresponda.

---

# EVOLUCION CONTINUA

El cierre del Nivel 09 no crea un Nivel 10.

A partir de este punto, el Proyecto Condor opera mediante ciclos de Evolucion Continua.

Los nuevos artefactos se incorporaran a este inventario cuando sean producidos y aceptados dentro de dichos ciclos.
