# Acta del Proyecto

## Objetivo

Definir la identidad, el propósito y los principios rectores del proyecto Cóndor.

---

## Propósito

Cóndor existe para construir una forma clara, coherente y evolutiva de representar conocimiento, arquitectura y software desde una misma base conceptual.

El proyecto busca que las decisiones importantes puedan documentarse, comprenderse, mantenerse y evolucionar sin perder su significado original.

---

## Visión

Construir un marco de trabajo que permita diseñar sistemas a partir del conocimiento que representan, antes de imponer estructuras técnicas como bases de datos, servicios, clases o pantallas.

---

## Principios

- La realidad del dominio es el punto de partida.
- El conocimiento debe representarse con claridad antes de implementarse.
- Cada documento debe tener una responsabilidad única.
- La simplicidad conceptual tiene prioridad sobre la complejidad técnica.
- La arquitectura debe evolucionar sin romper su coherencia.
- La documentación forma parte del producto.
- Toda decisión importante debe poder rastrearse.

---

## Estado

Este documento funciona como acta inicial y puede ampliarse cuando el marco de trabajo requiera mayor formalización.
