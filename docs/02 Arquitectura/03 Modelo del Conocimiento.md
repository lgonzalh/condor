# Modelo del Conocimiento

## Objetivo

Definir el modelo conceptual que Cóndor utiliza para representar conocimiento de forma simple, clara y evolutiva.

---

## Estructura

```text
03 Modelo del Conocimiento
│
├── 03.01 Unidad Fundamental de Conocimiento
├── 03.02 Relaciones del Conocimiento
├── 03.03 Estructuras del Conocimiento
├── 03.04 Reglas del Conocimiento
└── 03.05 Evolución del Conocimiento
```

---

## Documentos

| Documento | Propósito |
|-----------|-----------|
| 03.01 Unidad Fundamental de Conocimiento | Define la unidad mínima del conocimiento. |
| 03.02 Relaciones del Conocimiento | Define cómo se conectan las unidades fundamentales. |
| 03.03 Estructuras del Conocimiento | Define cómo se organizan las unidades fundamentales. |
| 03.04 Reglas del Conocimiento | Define las restricciones de composición y validación. |
| 03.05 Evolución del Conocimiento | Define el ciclo de vida del conocimiento. |

---

## Conceptos eliminados

Los siguientes conceptos no forman parte de la especificación oficial del modelo:

- Moléculas.
- Macromoléculas.
- ADN del conocimiento.
- Tabla periódica.

Estos conceptos fueron útiles como herramientas exploratorias, pero no son necesarios para la versión oficial del modelo.

---

```text
Conocimiento
      │
      ▼
Unidad Fundamental de Conocimiento
      │
      ▼
Relaciones
      │
      ▼
Estructuras
      │
      ▼

      │
      ▼

```

---

## Veredicto

El modelo resultante es más simple, más claro y más implementable.

Conserva la esencia del descubrimiento original, elimina complejidad innecesaria y establece una base sólida para el resto del marco Cóndor.
