# Estructuras del Conocimiento

## Objetivo

Definir cómo se organizan las Unidades Fundamentales de Conocimiento para representar conocimiento de mayor complejidad.

---

## Definición

Una estructura del conocimiento es un conjunto de Unidades Fundamentales de Conocimiento relacionadas que representan un único conocimiento compuesto.

---

## Principios

- Una estructura está compuesta por una o más Unidades Fundamentales de Conocimiento.
- Las unidades mantienen su identidad dentro de la estructura.
- Las relaciones determinan la organización de la estructura.
- Una estructura puede formar parte de otra estructura.

---

## Modelo

```text
Estructura
├── Unidad Fundamental de Conocimiento
├── Unidad Fundamental de Conocimiento
├── Unidad Fundamental de Conocimiento
└── Relaciones
```

---

## Reglas

- Toda estructura tiene un propósito.
- Toda estructura debe ser coherente.
- Toda estructura puede evolucionar sin perder su historial.

---

## Resultado

Las estructuras permiten representar conocimiento complejo a partir de elementos simples y reutilizables.
