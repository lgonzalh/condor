# DOC-005 Implementacion

**Estado:** Borrador  
**Version:** 0.1.0

---

# Objetivo

Definir los criterios para implementar Cóndor sin depender de una tecnologia especifica.

---

# Principio

Toda implementacion es una representacion del modelo, nunca el modelo.

---

# Requisitos

Una implementacion debe:

- Conservar el significado de los conceptos.
- Mantener las relaciones definidas por el modelo.
- Respetar la identidad de cada concepto.
- Cumplir los Fundamentos y la Especificacion de Cóndor.

---

# Independencia Tecnologica

Cóndor puede implementarse en cualquier tecnologia, por ejemplo:

- Bases de datos relacionales.
- Bases de datos orientadas a grafos.
- Documentos.
- Objetos.
- APIs.
- Sistemas distribuidos.
- Inteligencia Artificial.

La tecnologia elegida no modifica el modelo conceptual.

---

# Conformidad

Una implementacion es valida si representa fielmente el modelo definido por Cóndor.
