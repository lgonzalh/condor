# ESTANDAR_DOCUMENTAL

Version: 1.1.0
Estado: Activo
Nivel: Global
Clasificacion: Estandar

---

# Proposito

Definir el estandar obligatorio para todos los documentos oficiales del Proyecto Condor.

---

# Estructura obligatoria

Todo documento oficial debera incluir, cuando aplique:

- Version
- Estado
- Nivel
- Clasificacion
- Proposito
- Dependencias
- Documentos relacionados
- Impacto
- Historial de cambios

---

# Reglas permanentes

## Nombre del archivo

El nombre del archivo es permanente.

Nunca se agregaran sufijos de version.

Correcto:

- CONDOR_CONTEXTO_MAESTRO.md
- ADN_CONDOR.md
- KANBAN.md

---

## Version

La version existe unicamente dentro del documento.

---

## Actualizacion

Toda actualizacion sobrescribe el documento existente.

Git constituye el historial externo del proyecto.

---

## CondorEntregar

Todo CondorEntregar debera:

- generar un archivo Markdown descargable;
- mantener el mismo nombre del documento;
- actualizar la version dentro del documento;
- dejar el archivo listo para reemplazar el existente.

---

## Consolidacion

Las reglas permanentes se incorporan a los documentos existentes.

No se crearan documentos independientes para reglas menores.
