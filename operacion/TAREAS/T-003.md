# T-003 - Recomendador de modelos

Version: 1.0.0
Estado: Pendiente
Prioridad: Critica

## Objetivo

Crear el primer recomendador de modelos de Condor usando el Assessment y los modelos locales detectados, para producir una recomendacion explicable y adecuada al hardware real.

## Debe hacer

1. Leer el Assessment persistido.
2. Evaluar hardware y capacidades reales.
3. Evaluar los modelos disponibles.
4. Clasificar candidatos para desarrollo.
5. Considerar memoria y recursos disponibles.
6. Considerar capacidades especiales cuando puedan determinarse.
7. Producir una recomendacion explicable.
8. Indicar modelo recomendado y alternativas cuando sea posible.
9. Explicar brevemente el motivo.
10. Indicar limitaciones o incertidumbres.
11. Mantener toda la decision local.
12. No descargar modelos automaticamente.
13. Preparar la base para futuras recomendaciones de vision y herramientas.

## No debe hacer

- No descargar modelos automaticamente.
- No implementar Builder.
- No implementar Context Engine.
- No descubrir profundamente el proyecto.
- No asumir que el modelo mas grande es el mejor.
- No depender de internet.
- No cambiar automaticamente el modelo de T-002.
- No introducir servicios cloud.

## Principio

Prioridad de recomendacion:

1. Compatibilidad con hardware.
2. Capacidad para desarrollo.
3. Uso razonable de memoria.
4. Capacidad funcional requerida.
5. Estabilidad y disponibilidad local.
6. Alternativas si la primera opcion no es viable.

Debe preferirse una opcion viable y util frente a una teoricamente superior pero impracticable.

## Resultado esperado

```text
Condor analiza el equipo
        ↓
Condor analiza los modelos
        ↓
Condor compara capacidades
        ↓
Condor recomienda
        ↓
Modelo principal
Alternativas
Motivo
Limitaciones
```

## Pruebas

- reglas de recomendacion;
- memoria limitada;
- modelos ausentes;
- varios candidatos;
- Ollama/modelos ausentes;
- resultado explicable;
- arquitectura;
- prueba funcional real con los modelos actuales.

## Criterios de aceptacion

- Recomendacion real.
- Usa datos del Assessment.
- Distingue candidatos.
- Es explicable.
- No descarga modelos.
- Funciona sin internet.
- Degrada correctamente si faltan datos.
- Evidencia automatizada y funcional.
- Documentacion operativa actualizada.
- Continuidad posible sin esta conversacion.
