# PROTOCOLO_DOCUMENTACION

Version: 1.0.0
Estado: Activo
Nivel: 01 - Arquitectura
Clasificacion: Protocolo de Ingenieria

---

# Proposito

Definir el proceso obligatorio para crear, actualizar y preservar la documentacion de un proyecto desarrollado con Condor.

---

# Principios

- La documentacion forma parte de la ingenieria.
- La documentacion precede cuando el conocimiento es insuficiente.
- Toda implementacion actualiza el conocimiento.
- La documentacion es la fuente principal de verdad.

---

# Flujo

1. Identificar el conocimiento afectado.
2. Verificar si existe documentacion.
3. Crear o actualizar el documento correspondiente.
4. Registrar decisiones relevantes.
5. Actualizar el Kanban.
6. Validar consistencia entre documentacion e implementacion.
7. Finalizar la tarea.

---

# Reglas

- No duplicar conocimiento.
- Mantener un unico documento por tema.
- Conservar nombres estables de archivos.
- Registrar la version dentro del documento.
- Actualizar el historial de cambios cuando corresponda.
- Todo documento debe indicar sus dependencias cuando existan.

---

# Resultado esperado

Al finalizar cualquier tarea, el proyecto debera quedar mas documentado, mas comprensible y mas facil de continuar.
