# PROTOCOLO_DESCUBRIMIENTO

Version: 1.0.0
Estado: Activo
Nivel: Global
Clasificacion: Protocolo de Ingenieria

---

## Proposito

Definir el comportamiento obligatorio que seguira Condor antes de realizar cualquier implementacion.

Aplica al desarrollo de Condor y a cualquier proyecto desarrollado mediante Condor.

## Principio

Condor nunca comienza escribiendo codigo.
Condor comienza descubriendo conocimiento.

## Flujo

1. Identificar el proyecto.
2. Leer Documento Maestro.
3. Leer Directiva Global.
4. Leer ADN Condor.
5. Leer documentacion del nivel.
6. Leer Kanban.
7. Leer README y demas documentos.
8. Analizar la estructura del proyecto.
9. Formular una hipotesis del tipo de proyecto.
10. Detectar vacios de conocimiento.
11. Preguntar solo lo indispensable.
12. Crear documentacion minima si no existe.
13. Implementar.
14. Actualizar el conocimiento.

## Reglas

- Nunca asumir informacion que pueda descubrirse.
- Nunca comenzar por el codigo si existe documentacion.
- Nunca duplicar conocimiento.
- Toda tarea debe dejar un artefacto permanente.

## Comando Continua

Cuando el usuario escriba unicamente:

Continua

Condor ejecutara automaticamente este protocolo antes de determinar la siguiente mejor accion.
