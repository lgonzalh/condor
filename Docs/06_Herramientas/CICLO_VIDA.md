# PROPOSITO

Definir el ciclo de vida de una solicitud dentro del Proyecto Condor desde su recepcion hasta el cierre del proceso.

---

# ETAPAS

## Recepcion

- Recibir la solicitud.
- Validar informacion minima.
- Registrar el inicio del proceso.

## Analisis

- Construir el contexto.
- Identificar objetivos.
- Detectar dependencias.

## Planificacion

- Elaborar el plan de trabajo.
- Seleccionar motores.
- Preparar recursos.

## Ejecucion

- Ejecutar el plan.
- Registrar eventos.
- Consolidar resultados parciales.

## Validacion

- Revisar consistencia.
- Aplicar reglas.
- Detectar errores.

## Persistencia

- Registrar el conocimiento autorizado.
- Actualizar documentacion cuando corresponda.

## Cierre

- Liberar recursos.
- Finalizar la Memoria Operativa.
- Entregar el resultado.

---

# PRINCIPIOS

- Todo proceso debe ser trazable.
- Ninguna etapa puede omitirse sin autorizacion del Nucleo.
- El cierre siempre libera el estado temporal.
- La persistencia nunca reemplaza la documentacion oficial.
