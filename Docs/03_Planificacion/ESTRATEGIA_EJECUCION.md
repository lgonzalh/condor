---

# Proposito

Definir la estrategia oficial para ejecutar el Nivel 03 de forma ordenada, incremental y consistente con la arquitectura del Proyecto Condor.

---

# Principios

- Ejecutar un entregable a la vez.
- Respetar las dependencias documentales.
- Mantener un unico estado oficial del proyecto.
- Minimizar el trabajo manual del usuario.
- Consolidar el estado al cierre del nivel.

---

# Estrategia

1. Generar cada documento segun el plan documental.
2. Validar coherencia con los documentos ya existentes.
3. Evitar duplicidad de informacion.
4. Completar todos los entregables del nivel.
5. Ejecutar condorrevisar sobre el conjunto.
6. Ejecutar condorcongelar del nivel.
7. Ejecutar condorcerrar para preparar el siguiente nivel.

---

# Criterios de exito

- Todos los entregables existen.
- No existen contradicciones entre documentos.
- El nivel puede continuarse sin depender del historial del chat.
- El siguiente nivel queda preparado para iniciar.
